# iOS App

The iOS companion app for ObservationTracker is planned for **Milestone 4**.

See [`docs/Milestones.md`](../docs/Milestones.md) for the planned feature scope.

## Planned Stack

- **Language**: Swift
- **UI Framework**: SwiftUI
- **Local Storage**: SwiftData (iOS 17+)
- **Maps**: MapKit
- **Camera**: AVFoundation / PhotosUI
