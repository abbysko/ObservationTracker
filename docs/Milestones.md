# Milestones

Each milestone delivers a runnable app and focuses on incremental value.

1. Project skeleton
   - Folder structure
   - Development server
   - Theme
   - Bottom navigation

2. Lists screen
   - Built-in lists
   - Navigation

3. Custom list CRUD
   - Create, rename, delete, duplicate, edit items

4. Track screen
   - List picker
   - Start session

5. Observation grid
   - Tap to increment

6. Delayed sorting
   - 1–2s debounce before re-sorting

7. Long-press correction UI
   - Increment / decrement controls

8. Save session
   - Persist completed sessions to history

9. History screen
   - Browse saved sessions

10. Histogram (visualization)

11. Delete session

12. Dark mode

13. Browser persistence
   - IndexedDB repository implementation

14. Polish
   - Animation, accessibility, performance

15. Swift wrapper
   - WKWebView, native repository (SwiftData), sleep prevention, bridge
